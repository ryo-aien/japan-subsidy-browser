# 補助金・助成金ブラウザ 2026

日本国内の補助金・助成金を、地域・制度名・用途から横断的に探せる静的Webアプリです。

システム開発、DX、IT導入、新規事業、研究開発、副業・兼業人材の活用など、事業者が外部のIT・専門人材を活用するときに関係しやすい制度を中心に整理しています。

## 概要

このリポジトリでは、国および都道府県レベルの補助金・助成金情報をJavaScriptデータとして保持し、ブラウザ上で一覧・検索・詳細確認できるようにしています。

制度ごとに、次のような情報を確認できます。

- 制度名
- 対象地域
- 制度概要
- 補助率・上限額
- 個人事業主の対象可否
- フリーランス・副業人材への発注可否
- 対象経費
- システム開発・DXでの利用例
- 主な申請要件
- 申請期間・事業実施期間
- 交付決定前の契約・発注に関する注意
- 他制度との併用に関する注意
- 公式ページへのリンク

データ基準日は **2026-09-23** です。

## 収録状況

2026-09-23時点で、リポジトリ全体に **109制度** を収録しています。

特に、副業・兼業・プロフェッショナル人材などの外部専門人材活用に対する都道府県レベルの直接補助については、**44都道府県・46制度** を収録しています。

代表的な制度には、次のようなものがあります。

- 副業・兼業人材活用促進補助金
- プロフェッショナル人材確保支援補助金
- DX・デジタル化支援補助金
- システム開発・IT導入支援
- 新製品・新サービス開発支援
- 研究開発・実証支援
- 新事業進出・事業多角化支援

> このリポジトリは、国内のすべての補助金・助成金を完全に網羅することを保証するものではありません。市区町村独自制度や、短期間のみ公募される制度などは未収録の場合があります。

## 主な特徴

### 地域別に閲覧

左側のナビゲーションから、

`国 → 制度`

または

`都道府県 → 都道府県名 → 制度`

の順に確認できます。

### キーワード検索

制度名だけでなく、地域、用途、対象経費、DX、副業、システム開発などの情報をまとめて検索できます。

### 副業・兼業人材向け制度を収録

副業・兼業プロ人材を初めて活用する中小企業向けの制度を重点的に整理しています。

自治体によっては、

- 人材への報酬
- 業務委託料
- 人材紹介手数料
- 交通費
- 宿泊費

などが補助対象になります。

補助率 **8/10、上限50万円** 前後の制度が複数の都道府県で実施されていますが、補助率・上限・対象経費・申請条件は自治体ごとに異なります。

### スマートフォン対応

レスポンシブUIになっており、PC・スマートフォンの両方で閲覧できます。

### ビルド不要

フレームワークやビルドツールを使用していません。

HTML / CSS / JavaScriptのみで構成されているため、そのままGitHub Pagesなどで公開できます。

## ファイル構成

```text
.
├── index.html
├── data-1.js
├── data-2.js
├── data-3.js
├── data-4.js
├── data-5.js
├── details.js
├── details-sidejobs.js
├── favicon.ico
├── favicon-16x16.png
├── favicon-32x32.png
└── .github/
```

### `index.html`

画面UIと検索・ナビゲーション・詳細表示のロジックを含みます。

### `data-1.js` ～ `data-5.js`

補助金・助成金の基本データを保持します。

各制度はおおむね次の形式です。

```js
{
  scope: "都道府県",
  region: "神奈川県",
  name: "神奈川県副業・兼業人材活用補助金",
  usage: "副業・兼業プロ人材の報酬・人材紹介手数料等",
  individual: "可",
  freelancer: "可",
  limit: "8/10・50万円",
  status: "～2026/12/28",
  url: "https://...",
  id: "s105"
}
```

### `details.js`

各制度の概要、対象者、対象経費、利用例、申請条件などの詳細情報を補完します。

### `details-sidejobs.js`

副業・兼業・プロフェッショナル人材活用系制度について、都道府県ごとの条件差を追加で補完します。

## ローカルでの確認

静的ファイルなので、簡易HTTPサーバーを起動すれば確認できます。

Pythonがある場合:

```bash
python -m http.server 8000
```

その後、ブラウザで次を開きます。

```text
http://localhost:8000/
```

単純に `index.html` を直接開くこともできますが、ブラウザや環境によってはローカルファイルの制約があるため、HTTPサーバー経由での確認を推奨します。

## データを追加・更新する場合

基本データは `data-*.js` に追加します。

既存IDと重複しない一意な `id` を設定してください。

詳細情報が必要な場合は `details.js` または `details-sidejobs.js` に補足を追加します。

更新時は特に次の項目を確認してください。

1. 制度が2026年度に実施されているか
2. 公式ページまたは公式公募資料が存在するか
3. 補助率・上限額
4. 対象事業者
5. 対象経費
6. 申請期限
7. 契約・発注・支払いと交付決定の前後関係
8. 人材紹介会社やプロフェッショナル人材戦略拠点の利用要件
9. 他制度との重複利用制限

同じ制度を名称違いで二重登録しないよう、URL・対象地域・制度内容も確認してください。

## データの考え方

このサイトは、補助金を「利用できる」と断定するための判定ツールではなく、候補制度を探しやすくするためのブラウザです。

自治体の制度は、年度途中でも次のような変更が発生することがあります。

- 予算上限による早期終了
- 追加募集
- 申請期間の変更
- 補助率・上限額の変更
- 対象経費の変更
- 交付要綱・公募要領の改定

実際に申請する場合は、必ず各制度の公式ページ、最新の公募要領、交付要綱、申請手引きを確認してください。

## GitHub Pages

このリポジトリは静的サイトとしてGitHub Pagesで公開できます。

`Settings → Pages` から公開方法を設定してください。

GitHub Actionsによるデプロイを設定している場合は、`main` ブランチへの更新を起点に公開できます。

## 免責事項

掲載情報は調査時点の公開情報をもとに整理していますが、正確性・完全性・最新性を保証するものではありません。

補助対象の可否、申請要件、契約条件、補助対象経費などについては、各制度の実施主体が公開する最新情報を優先してください。
