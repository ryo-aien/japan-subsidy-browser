# 補助金・助成金ブラウザ 2026

国および都道府県レベルの、システム開発・DX・新事業・研究開発・副業/兼業人材活用などに関連する補助金・助成金を閲覧する静的サイトです。

- 左：国 / 都道府県 → 制度名
- 右：制度詳細、個人事業主可否、フリーランス発注可否、上限、募集状況、公式リンク
- 検索対応
- スマホ対応
- 副業・兼業等の外部専門人材活用への都道府県レベル直接補助：44都道府県・46制度を収録（2026-09-23時点）
